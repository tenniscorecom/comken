# 機能カタログ — 用途別早見表

「やりたいこと」から、使うクラスや関数と import を探すための入口。
型ヒント付きの完全な署名・引数・戻り値・例外は [API.md](API.md) を参照する。
VS Code では、名前にマウスを重ねると同じ説明を Pylance のホバーで確認できる。
動く例は [README.md](../README.md) の各節と `examples/` を参照する。

## 早見表

| やりたいこと | 使うもの | import |
|---|---|---|
| CSV を読む | `CsvReader` | `from comken.csv import CsvReader` |
| CSV を書く | `CsvWriter` | `from comken.csv import CsvWriter` |
| Excel を読み取る | `ExcelReader` | `from comken.excel import ExcelReader` |
| Excel を書き込む | `ExcelWriter` / `Sheet` | `from comken.excel import ExcelWriter` |
| 文字コード・色・形式・並び順を指定する | `Encoding` / `Color` / `FileFormat` / `SortBy` | `from comken.constants import Encoding, Color, FileFormat, SortBy` |
| Excel の既存数式の結果・マクロ・パスワード保存 | `ExcelComHandler` | `from comken.windows import ExcelComHandler` |
| Access のマクロ実行・CSV 出力 | `AccessDatabase` | `from comken.access import AccessDatabase`（既定でローカルコピー、元 DB を直接開く場合は日時付きバックアップ） |
| Classic Outlook の受信メール読み取り・下書き作成（[詳細](Outlook操作.md)） | `Outlook` / `MailMessage` | `from comken.outlook import Outlook, MailMessage` |
| ファイルを探す・動かす | `FileFinder` ほか | `from comken.utils.files import FileFinder` |
| 日付入りファイルをまとめて取得する | `FileFinder.dated` | `FileFinder(folder).dated()` |
| データの差分を取る | `diff_rows` | `from comken.utils import diff_rows` |
| 差分結果の型を確認する | `DiffResult` / `RowChange` | `from comken.utils import DiffResult, RowChange` |
| 現在時刻・今日の日付を取る | `now()` / `today()` | `from comken.utils import now, today` |
| ブラウザを自動操作する | `Browsers` + Page Object | `from comken.browser import Browsers` |
| 画面クラス・ダウンロード先を作る | `Page` / `DownloadDir` | `from comken.browser import Page, DownloadDir` |
| Salesforce のレコードを読み書きする（[詳細](Salesforce.md)） | `Salesforce` | `from comken.salesforce import Salesforce` |
| Salesforce のレポートを取得する | `ReportApi` | `sf.report.run("00O...")`（上限 2000 行） |
| Salesforce の API 使用量を記録する | `ApiMetrics` / `ApiUsage` / `ComponentStat` / `RetryReason` | `sf.metrics.log_summary()` |
| パスワード・client_secret を安全に持つ | `Credentials` | `from comken.credentials import Credentials` |
| 認証情報を JSON から取り込む | `import_json` | `python -m comken.credentials import 認証情報.json` |
| 認証情報を1件ずつ扱う | `load_credential` / `save_credential` / `save_credentials` / `delete_credential` / `list_names` / `CREDENTIALS_PATH` | `from comken.credentials import load_credential` |
| 社内 RPA 基盤から実行する | `backoffice` / `intranet` | `from comken.run import backoffice` |
| config.ini を読む | `Config` | `from comken import Config` |
| ログを出す | 標準 `logging` | `logging.getLogger(__name__)` |
| 本番前に書き込みなしで動作確認 | `dry_run` | `from comken import dry_run` |
| 実行モード中か調べる | `is_debug` / `is_dry_run` | `from comken import is_debug, is_dry_run` |
